# Lastreia Frontend

Frontend do posicionamento Lastreia:
- Aquisicao como Infraestrutura
- Sinais, nao leads

## Stack

- Next.js App Router
- TailwindCSS + shadcn/ui
- Zustand
- React Query
- Framer Motion

## Nomenclatura principal da UX

- Leads + Sinais
- Sequencias
- Inteligencia
- Descoberta de Leads

## Execucao

```bash
npm install
npm run dev
```

A aplicacao roda em `http://localhost:3000`.

## Checks de qualidade

```bash
npm run lint
npm run build
```
