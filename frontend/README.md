# Leadflow Frontend

Frontend for Leadflow positioning:
- Acquisition as Infrastructure
- Signals, not leads

## Stack

- Next.js App Router
- TailwindCSS + shadcn/ui
- Zustand
- React Query
- Framer Motion

## Main UX naming

- Prospects + Signals
- Sequences
- Intelligence
- Lead Discovery

## Run

```bash
npm install
npm run dev
```

App runs on `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run build
```
